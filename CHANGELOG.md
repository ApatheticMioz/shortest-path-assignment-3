# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - Initial Archival Release

### Added
- Dijkstra's algorithm implementation with priority queue optimization
- Bellman-Ford algorithm with negative cycle detection
- Floyd-Warshall all-pairs shortest path algorithm
- Johnson's algorithm for sparse graphs with negative weights
- Interactive mode for solving custom graphs from input file
- Experimental analysis mode with random graph generation
- Benchmark harness for statistical analysis (500 iterations)
- Graphviz DOT file export for visualization

### Changed
- Repository standardized for public archival
- Source files renamed to standard conventions
- Documentation updated with clear build and usage instructions

### Removed
- Assignment-specific files (PDF report, LaTeX source)
- Generated output files (DOT graphs, statistics reports)
